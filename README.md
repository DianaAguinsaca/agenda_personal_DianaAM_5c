# Mi Agenda Verde 🌿

## Dedicatoria
Este proyecto está dedicado con mucho amor a mi papá.

Fue diseñado pensando en él, para que pueda manejar su trabajo de una forma más fácil, ordenada y sin perderse.

Yo, como su hija, quise crearle una herramienta que le ayude a él y a toda nuestra familia a llevar su agenda.

## ¿Para qué sirve Mi Agenda Verde?
Mi Agenda Verde es una agenda personal en web donde cada usuario puede registrarse, iniciar sesión y gestionar sus propios contactos.

Esta agenda fue creada para el negocio familiar de mi papá, que se dedica a la compra y venta de material, como por ejemplo plástico.

## ¿Quiénes la usan?
La agenda no solo la usa mi papá, también la usamos nosotros como sus hijos y sus trabajadores.

Cada trabajador tiene su propio usuario y su propia contraseña.
Así cada quien entra a su cuenta y puede ver y manejar la agenda de trabajo.

## ¿Qué pueden hacer los trabajadores?
Con su usuario y contraseña, los trabajadores pueden:

- Agregar contactos nuevos de compradores del material
- Ver los contactos que ya están registrados
- Editar un contacto si cambia su número o su información
- Eliminar contactos cuando ya no se trabaja con ese comprador
- Ver cómo se va actualizando la agenda día a día

Así, cuando un comprador ya no compra material, se elimina de la agenda.
Y cuando llega un comprador nuevo, se agrega a la agenda.

De esta forma siempre sabemos con quiénes estamos trabajando, a quiénes les entregamos el material y quiénes ya no forman parte del trabajo.

## Tecnologías utilizadas
- PHP
- MySQL
- HTML
- CSS
- XAMPP / phpMyAdmin

## Requisitos para su ejecución
- Tener instalado XAMPP
- Tener Apache y MySQL activados
- Navegador web

## Pasos para instalar la aplicación
1. Copiar la carpeta del proyecto en la carpeta htdocs de XAMPP
2. Abrir phpMyAdmin y crear la base de datos
3. Importar el archivo agenda_verde.sql
4. Abrir en el navegador: localhost/agenda_personal_Diana AM_5c
5. Registrarse con un usuario nuevo e iniciar sesión
6. Cerrar sesion
